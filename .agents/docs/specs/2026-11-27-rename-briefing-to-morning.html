Decision log

How far does the rename go?

Folder and skill name (skills/morning/, /daily-workflow:morning), the "Copy done" prompt (/daily-workflow:morning done …), the name in the README, plugin and marketplace descriptions ("Morning" instead of "Daily Briefing"), the plan page text ("work briefing" → "work plan"), docstrings and comments. One name everywhere. Folder, skill name and the "Copy done" prompt. Descriptions and texts keep "Daily Briefing". A smaller change, but two names for the same thing.

Recommended option accepted: one name everywhere in the plugin, the marketplace and the root README.

What about the update, home and done modes?

/daily-workflow:morning update, … home, … done <file>. One skill, the same rules and sources. A new /daily-workflow:home for the home plan, update and done stay under morning. Clearer names, but two skills share the plan rules.

Recommended option accepted, although "morning update" runs after the daily and "morning home" may sound odd: the modes stay as they are, only the skill name changes. The wording is settled in D5.

Should the old briefing command keep working?

A personal plugin, one user. An old prompt copied before the change can be fixed by hand. A small briefing skill that only forwards to morning (with the same arguments). Nothing breaks, but code stays to remove later.

Recommended option accepted: no alias; plan pages get the new prompt on the next render anyway.

What about the collision with the existing "morning" skill?

The skill is named morning, called as /daily-workflow:morning; the skill description has no generic phrases like "morning brief", but "day plan", "plan dnia", Deep Work. Matches the request, the collision only with a bare /morning. No collision, but not the name you asked for.

Recommended option accepted: the name morning, documented with the daily-workflow: prefix, and a description that does not compete with anthropic-skills:morning.

How to tell the skill name "Morning" from the "morning" stage in the texts, and what replaces the noun "the briefing"?

The skill is the proper name "Morning"; the noun "the briefing" becomes "the day plan"; the stage keeps the lowercase morning.

Proposed after a review of the finalized spec and accepted. It refines D1: where "briefing" names the skill, the text says "Morning"; where it means what the skill produces, it says "the day plan". Lowercase "morning" keeps its one meaning, the stage before the daily (stage: "morning", "the morning plan"). Where both would stand next to each other (the "Morning (no argument)" section, the plugin.json description), the stage wording is rephrased.
